# 考试内容：

- 英语： 单词、语法、长难句、作文
- 数学： 高数、线代、概率
- 408： 数据结构、操作系统、计算机组成原理、计算机网络
- 政治：马原、毛中特、近代史、时政

----
# 各科开始时间

## &emsp;英语 （ 26.6开始 ）
>
| 内容 | 开始时间 | 备注 |
| :--- | :---: | :--- |
| **单词** | 26.6  | 单词贯穿全程，前期2小时，后期1小时 |
| **语法** | 26.11 | 速通基础语法尝试四级 |
| **长难句** | 27.2 | 开始啃阅读，看文献增加单词熟练度 |
| **作文** |27.5 | 模版式背作文背套路 |

基本稳定在每天2h左右的学习时间
- 早上新单词背诵 0.5h
- 晚上复习和重温 0.5h
- 前期： 时间巩固背诵--时间占用少点 0.5h
- 中期： 看课学习 or 精读 -- 1h ~ 1.5h
- 后期： 真题卷子每天一张（不写作文）or  $写（小作文 + 大作文 ）\times 2$ -- 2h 

## &emsp;数学 （ 26.7开始 ）
>
 基础一轮： 张宇30讲+1000题 用 汤家凤1800辅助学习 
 强化二轮： 张宇36讲 + 李永乐660题 +  李林880题 + 李艳芳900题 
 冲刺三轮： 到时各大真题+预测卷

整体节奏不赶，多花时间在写题上
- 基础一轮： 平均一节课一个小时左右$（\times1.5倍+理解）$ 两天为一个单位完成每一节课对应章节的题目和思考，多余时间尝试整理  -- 2天3h （可以一周选一天放假哦）
- 强化二轮： 
	1. 前期 - 专注于视频看课完成教材对应题目，重心在笔记和核心理解 ->  视频过起码两遍，对所有核心内容了解完善笔记 -- 1.5h
	2. 后期 - 每天刷题总结思考题目，完成额外的3本习题册（一本一本刷） -- 1.5h~2h
- 冲刺三轮： 一天半张卷子+批改复盘 -- 2h

##  &emsp;408 （ 26.7开始 ）

> 只使用王道版本教材
> &emsp;对于数据结构每周仔细剖析一个算法理解并且达到手写板子并且完成几道对应题目
>&emsp;偶尔加训codeforces or 牛客 or atcoder

对于我个人而言是不需要再仔细去学数据结构，主要是别的背的东西能记得

- **第一阶段**： 看王道视频课配合对应的教材（只写选择题）--1.5h
	&emsp;&emsp;**观看顺序**：
	&emsp;&emsp;&emsp;$\boldsymbol{（ 操作系统 \rightarrow 计算机组成原理 \rightarrow 计算机网络） \times 2 \rightarrow 数据结构}$
- **第二阶段**： 按照顺序总结王道所有教科书每章节都进行总结整理 --1.5h
- **第三阶段**： 历年15年真题以及各种卷子，一天一张 一周三次 -- 4h ~ 5h

## &emsp;政治（ 27.6开始 ）
>政治主要就是背诵看时政，调好时间和顺序即可，拉开的分不大适当花时间就行
>一轮：徐涛强化课 + 核心考案 + 肖秀荣1000题
>二轮：二刷1000题 + 徐涛核心模拟卷 + 肖八
>三轮：考前卷+肖四

政治我总结的经验贴都是大部分精力在选择题
从六月开始一刷完课程和1000题以后就是刷题+背自己整理的手册
自己手册可以从九月份开始整理，每天尽可能花0.5h~1h刷客观题（给自己讲懂）然后花半小时背诵自己的手册 -- 1h~1.5h


----
# 总结
&emsp;&emsp;大部分时间应该花在数学和408上面，但是由于英语太差的缘故还是花更多时间在英语上，政治晚点开始不用花太多时间，注意休息基本上是学六休一，因为一些上课啊各种原因时间安排比较重要，$英语>数学>408$ 这个顺序取舍每天的时间，尽可能的减少特殊时间，要兼顾打游戏+健身来调节生活。前期学习时长大部分是在6h以内，完全是有很多时间来规划自己的生活和调节自己，重点是坚持下去，后期一天最多也不过是10h，对标高中其实也还好，加油吧！！！
